# WeatherPort

## Задание

### Лабораторная работа 1
```
Есть устройство, которое публикует по серийному порту или интерфейсу USB
текущую температуру окружающей среды. Необходимо написать на C\C++ кроссплатформенную программу,
которая считывает информацию с порта и записывает ее в лог-файл. Каждый час программа считает
среднюю температуру за час и записывает ее в другой лог-файл.
Средняя температура за день записывается в 3й лог-файл. Лог файл со всеми измерениями должен
хранить только измерения за последние 24 часа, лог-файл со средней температурой за час должен
хранить только измерения за последний месяц, лог файл со средней дневной температурой накапливает
информацию за текущий год.
```

### Лабораторная работа 2
```
В программу, выполненную в ходе предыдущего задания, добавить функционал сетевого сервера
с возможностью публиковать по HTTP-запросу текущую температуру, а также статистику за выбранный
период времени. Добавить функционал сохранения логов в базу данных вместо файлов.
Написать для своего сервера клиентское веб-приложение на любом языке программирования
(C/C++ + HTML + CGI, PHP, Python, Java...), отображающее данные в наглядном виде (таблицы или графики).
```

## Архитектура (Лабораторная 2)

### C++ Сервер (main.cpp)
- Чтение температуры с последовательного порта
- Сохранение данных в SQLite базу данных
- HTTP сервер (порт 8080) с REST API
- Автоматическая агрегация статистики (почасовая, дневная)

### База данных (SQLite)
Три таблицы:
- `measurements` — все измерения (хранятся 24 часа)
- `hourly_stats` — средние за час (хранятся 30 дней)
- `daily_stats` — средние за день (хранятся за текущий год)

### HTTP API Endpoints
| Endpoint | Описание | Параметры |
|----------|----------|-----------|
| `GET /api/current` | Текущая температура | - |
| `GET /api/measurements` | Измерения за период | `hours` (по умолчанию 24) |
| `GET /api/hourly` | Почасовая статистика | `days` (по умолчанию 7) |
| `GET /api/daily` | Дневная статистика | `days` (по умолчанию 30) |
| `GET /api/stats` | Общая статистика (min/max/avg) | - |

### Веб-клиент (Flask + Chart.js)
- Отображение текущей температуры в реальном времени
- Графики измерений, почасовой и дневной статистики
- Таблица последних измерений
- Автообновление каждые 5 секунд

## Сборка и запуск

### macOS

```bash
# Установка зависимостей
brew install socat sqlite3

# Сборка
mkdir -p build && cd build
cmake ..
cmake --build .

# Создание виртуальных портов
socat -d -d pty,raw,echo=0 pty,raw,echo=0
# Вывод: /dev/ttys002 и /dev/ttys003

# Терминал 1: Запуск sender (эмулятор устройства)
source .venv/bin/activate
python sender.py --port /dev/ttys003 --interval 10

# Терминал 2: Запуск C++ сервера
./build/logger /dev/ttys002 9600

# Терминал 3: Запуск веб-клиента
cd web_client
pip install -r requirements.txt
python app.py
```

### Linux

```bash
# Установка зависимостей (Debian/Ubuntu)
sudo apt install cmake g++ socat libsqlite3-dev python3-pip

# Сборка
```

## Использование

1. **Запустите C++ сервер** — он будет слушать порт для температуры и HTTP запросы на порту 8080

2. **Запустите sender** — эмулятор устройства, отправляющий температуру

3. **Запустите веб-клиент** и откройте в браузере:
   - http://localhost:5000 — веб-интерфейс с графиками

4. **Или используйте API напрямую:**
   ```bash
   # Текущая температура
   curl http://localhost:8080/api/current

   # Измерения за последние 6 часов
   curl "http://localhost:8080/api/measurements?hours=6"

   # Почасовая статистика за неделю
   curl "http://localhost:8080/api/hourly?days=7"

   # Дневная статистика
   curl http://localhost:8080/api/daily

   # Общая статистика
   curl http://localhost:8080/api/stats
   ```
